# moeDocLN
Một thư viện nhỏ dành cho trang web DocLN
## Giới thiệu
**moeDocLN** là một thư viện python nhỏ dành cho trang web DocLN, được thiết kế để tự động hóa một số thứ.
## Tính năng
Nhanh, dễ làm quen.
## Hướng dẫn cài đặt 
### Bằng tay
```bash
python -m pip install DocLN-API 
```
Rồi import và dùng.
